# Changelog

## 1.5 (2026-11-02)

First public release.

- 16-line IndoPak Mushaf with colour-coded tajweed, 548 pages, fully offline.
- Resume from the last page, or open straight onto it at start.
- Surah, Para and Manzil lists with verse and page counts; swipe between them.
- Forgiving Surah search: numbers, English or Arabic names, common spellings and typos.
- Bookmarks with default or custom names.
- Clean reading screen with a faint ⋮ menu: bookmark, index, page style, Fill screen, settings.
- Aligned pages, pinch and double-tap zoom, optional fill-screen mode that keeps clear of punch-holes and notches.
- App theme (Light / Dark / System) and page style (Auto / Original / Night / Invert / Warm).
- Extras: Dua Khatm-ul-Quran, stop signs and tajweed rules.
- "Found a mistake?" note in the app and README, with GitHub forms to report a mistake or a bug.
